## Organización del repositorio

* `README.md`: presentación de la empresa y del repositorio.
* `CONTRIBUTING.md`: reglas de trabajo del equipo.
* `.gitignore`: archivos y carpetas que Git debe ignorar.
* `src/`: código fuente de los proyectos.
* `docs/`: documentación y bitácoras.
* `equipo/`: perfiles de los integrantes.
