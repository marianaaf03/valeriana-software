Un script en Python que procesa datos de ejemplo de nuestra empresa de software para generar un reporte automatizado con resumen y su respectiva grafica, diseñado para optimizar el control de solicitudes y ventas de nuestros clientes.
* **Opcion A:** Reporte automatico.
* **Mariana Alvarez Franco:** Desarrollo de la estructura base, gestion de ramas y automatizacion.
* **Sara Valeria Buitrago:** Definicion de datos, documentacion y revisiones.
* **Kickoff:** Configuracion del tablero Kanban, repositorio, reglas y definicion de tickets.
* **Encargo 2;** Script en Python para la lectura de datos y generacion de reportes con manejo de errores.
* **Encargo 3:** Automatizacion del script en la nube mediante GitHub Actions (CI/CD).
* **Encargo 4:** Publicacion del reporte en una pagina web con GitHub Pages.
